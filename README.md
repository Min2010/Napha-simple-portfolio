# Napha Portfolio

A clean, modern data analyst portfolio built with HTML, Tailwind CSS, and JavaScript.

## Features
- **Responsive Design**: Works on mobile, tablet, and desktop.
- **Dark Mode**: Supports system preferences and manual toggle.
- **Interactive Animations**: Smooth scroll and reveal-on-scroll effects.
- **Tech Stack**:
  - Tailwind CSS (via CDN)
  - Vanilla JavaScript
  - Inter Font (Google Fonts)

## Structure
- `index.html`: Main portfolio structure.
- `style.css`: Custom styles and scrollbar overrides.
- `script.js`: Theme switching and animation logic.

## Getting Started
Simply open `index.html` in your browser to view the portfolio.
