# 📊 Napha.data | Data Analyst Portfolio

Welcome to my professional portfolio website. This project showcases my expertise in data analysis, statistical modeling, and data visualization through a clean, modern, and responsive web interface.

## 🚀 Features

- **Modern UI/UX**: Built with a focus on readability and professional aesthetics.
- **Dark Mode Support**: Automatically respects system preferences and includes a manual toggle for dark/light themes.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens using Tailwind CSS.
- **Interactive Elements**:
  - Smooth scrolling for navigation.
  - Reveal-on-scroll animations for dynamic content presentation.
  - Interactive theme switcher.
- **Optimized Performance**: Uses Tailwind CSS CDN for rapid development and clean vanilla JavaScript for interactivity.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure.
- **Tailwind CSS**: Utility-first styling (via CDN).
- **JavaScript (ES6+)**: Custom animations and theme logic.
- **Google Fonts**: Inter font family for professional typography.

## 📂 Project Structure

- `index.html`: The main entry point containing the portfolio sections (Hero, About, Experience, Skills, Contact).
- `script.js`: Contains logic for theme switching, mobile menu, navbar effects, and intersection observer animations.
- `style.css`: Custom CSS for scrollbar styling and base anti-aliasing.

## 🏁 Getting Started

To view this portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Min2010/Napha-simple-portfolio.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Napha-Portfolio
   ```
3. Open `index.html` in your favorite web browser.
